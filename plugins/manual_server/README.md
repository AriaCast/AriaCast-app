# Manual Server Entry Plugin

Version: 1.1.0

## Description
Allows manually adding a server by IP and Port for cross-VLAN or Tailscale/VPN casting where mDNS or SSDP discovery cannot cross subnet boundaries.

## Files
- `manual_server.json`: Plugin manifest metadata
- `manual_server.js`: Plugin logic script

## Upstream
Tracked in [AriaCast-android-plugins](https://github.com/AriaCast/AriaCast-android-plugins).
